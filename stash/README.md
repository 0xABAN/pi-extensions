# stash

ctrl+s stashes the editor text and clears the editor. Press it again in an empty editor to bring the text back. There is one slot, kept in `stash.txt` in Pi's agent folder, and a `stash` badge shows while it holds text.

Based on [pi-powerline-footer](https://github.com/nicobailon/pi-powerline-footer) · [MIT](LICENSE)
